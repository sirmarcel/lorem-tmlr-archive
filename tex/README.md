# Paper source

LaTeX source of *Learning Long-Range Representations with Equivariant Messages* (LOREM), published in TMLR (04/2026).

- `main.tex`: the paper (with `snippets.tex` for macros). Revision changes relative to the accepted version are marked `\rev{...}` (new) and `\revs{...}` (superseded text).
- `main-accepted.pdf`: the TMLR-typeset version as published. The source here is ahead of it; see the note in the top-level README.
- `comparison.tex` / `comparison.pdf`: standalone document comparing originally-published against revised numbers (biodimers per-class correction, matched-accuracy runtime benchmark).
- `figures/`, `tables/`: paper figures and tables, generated by the scripts in `../results/`.
- `zotero.bib`, `custom.bib`: bibliography. `tmlr.sty`, `tmlr.bst`, `fancyhdr.sty`, `math_commands.tex`: TMLR style files (see `LICENSE`).

Build with `latexmk -pdf main.tex`; the comparison document builds standalone via `latexmk -pdf comparison.tex`.
