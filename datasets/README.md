# Datasets

This contains datasets used in the paper in `.xyz` (extended) format. All units are eV and Å; energies are not modified (composition baseline is removed elsewhere).

## Preparing data for training

`marathon` uses a custom data format for efficient reading with `grain`, based on `mmap`-ed arrays. The `prepare.py` script in this folder runs the necessary processing to generate this from the input `.xyz` files presented here. As described in the top-level `README.md`, `$DATASETS` should point at this `datasets/` folder (`export DATASETS="$(pwd)/datasets"`); `prepare.py` then reads the shipped `.xyz` files from here and writes the processed `mmap` datasets alongside them.

The SN2 data is obtained from [Zenodo](https://zenodo.org/records/14750286). Here's the snippet to convert the `.npz` to `ase.Atoms`, reversing the shifts done in the zenodo release:

```python

from ase.calculators.singlepoint import SinglePointCalculator
from ase import Atoms

data = np.load("sn2_reactions_shifted.npz")
shifts = {
    1: -3.5921101,
    6: -1.71485694,
    9: -0.97762923,
    17: -0.23682422,
    35: 0.08449515,
    53: 0.17498543,
}

total = data["positions"].shape[0]
node_mask = np.array(data["node_mask"])
positions = np.array(data["positions"])
forces = np.array(data["forces"])
energy = np.array(data["energy"])
atomic_numbers = np.array(data["atomic_numbers"])

def get_atoms(i):
    mask = node_mask[i]
    pos = positions[i][mask]
    f = forces[i][mask]
    e = energy[i][0]
    z = atomic_numbers[i][mask]

    offset = sum([shifts[Z] for Z in z])

    a = Atoms(positions=pos, numbers=z)
    c = SinglePointCalculator(a, forces=f, energy=e + offset)
    a.calc = c

    return a

# the split was: 405k training, 5k valid, 42708 test

```

The minimum energy paths are obtained the same way, except that the shift is omitted.

For convenience we include `sn2_split_indices.npz` with `train_indices` (405,000), `valid_indices` (5,000), and `test_indices` (42,708) arrays — indices into `sn2_reactions_shifted.npz` in its on-disk order (452,709 structures total). These reproduce the shipped `sn2_{train,valid}.xyz`.

ADAPT data comes from the silicon point-defect dataset of *ADAPT: Lightweight, Long-Range Machine Learning Force Fields Without Graphs* (Dramko et al., [arXiv:2509.24115](https://arxiv.org/abs/2509.24115)). We use v3 of the data share at [doi:10.5281/zenodo.17411327](https://doi.org/10.5281/zenodo.17411327).

Due to its size (\~260k structures, 217 atoms each), we do not redistribute the training data here. Please download `dataset_train_pbc_updated.xyz` from the Zenodo record. The file provides DFT energies and forces in `REF_energy` and `REF_forces`; `prepare.py` renames these to `energy` / `forces` and attaches an ASE `SinglePointCalculator` before writing the marathon mmap.

Our train/validation split is generated by `prepare.py`, which processes every dataset in this folder sequentially (it takes no command-line arguments; the ADAPT split parameters are hardcoded: validation fraction 0.20, seed 23). This uses `np.random.default_rng(23)` to shuffle the 258,716 structures and takes the first 20% (51,743) as validation and the rest (206,973) as training. For convenience we also include `adapt_split_indices.npz` containing the resulting `train_indices` and `valid_indices` arrays (indices into `dataset_train_pbc_updated.xyz` in its on-disk order).

For the hyperparameter sweep (Sec. A.5), a 10,000-structure debug subset was used (9,500 train / 500 valid, 100 epochs). This is generated by `prepare.py` alongside the full dataset: `np.random.default_rng(0)` shuffles the full dataset and takes the first 10,000 structures, which are then split with 5% validation fraction (also seed 0).

For the test set, we reconstruct the "official" 100-structure benchmark from the ADAPT paper's Table 2. These are the first frames from each of the 100 held-out test trajectories; the original `testData.extxyz` distributed by ADAPT had a global off-by-one bug in the energy column (since fixed upstream), so we rebuild the benchmark from positions/species in the extxyz combined with correct energies and forces from `pickleFiles/11.pickle`, and write the result to `adapt_test_official.xyz` (included here, 100 structures, 217 atoms, cubic cell `a = 16.406184 Å`, PBC on all axes).
